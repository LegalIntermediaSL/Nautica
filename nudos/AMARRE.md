# Nudos de Amarre

Los nudos de amarre sirven para sujetar un cabo a una estructura (un noray, un mástil, una argolla) o para crear una gaza (un lazo) que no se escurra.

## 1. As de Guía (Bowline)

Es el nudo más importante en náutica, conocido como "el rey de los nudos". Sirve para hacer una gaza (un lazo) fijo en el extremo de un cabo que no se escurre ni se aprieta bajo tensión.

![As de Guía](https://upload.wikimedia.org/wikipedia/commons/thumb/1/14/Bowline.jpg/640px-Bowline.jpg)

*   **Uso:** Amarrar drizas, escotas, encapillar un cabo a un noray, izar personas, maniobras de rescate.
*   **Tutorial en YouTube:** [Cómo hacer el As de Guía (Búsqueda en YouTube)](https://www.youtube.com/results?search_query=como+hacer+nudo+as+de+guia)

## 2. Ballestrinque (Clove Hitch)

Es un nudo de amarre rápido, utilizado para sujetar un cabo a un poste, mástil o noray cilíndrico.

![Ballestrinque](https://upload.wikimedia.org/wikipedia/commons/thumb/c/c5/Clove_hitch.jpg/640px-Clove_hitch.jpg)

*   **Uso:** Colgar las defensas del barco, amarrar temporalmente a un pilote o candelero.
*   *Precaución:* Puede aflojarse si la tensión no es constante o si el cabo gira. Suele rematarse con un par de cotes de seguridad para evitar que se deshaga.
*   **Tutorial en YouTube:** [Cómo hacer el Ballestrinque (Búsqueda en YouTube)](https://www.youtube.com/results?search_query=como+hacer+nudo+ballestrinque)

## 3. Vuelta de Rezón o de Ancla (Anchor Hitch)

Es un nudo muy resistente, diseñado específicamente para unir un cabo a una argolla o al arganeo de un ancla o rezón.

*   **Uso:** Amarrar el cabo de fondeo (línea de fondeo) al ancla. Tiene la ventaja de que no se aprieta tanto como para no poder deshacerse después de haber soportado mucha tensión.
*   **Tutorial en YouTube:** [Vuelta de Rezón (Búsqueda en YouTube)](https://www.youtube.com/results?search_query=vuelta+de+rezon+nudo)
