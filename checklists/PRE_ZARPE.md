# Checklist de Pre-Zarpe (SOP-01)

Este checklist debe leerse en voz alta por el Patrón y ser confirmado por el Tripulante de guardia antes de soltar la última amarra. 

## 1. Chequeo de Motor (Método W.A.B.E.R.)
| Sistema | Comprobación | Estado |
| :--- | :--- | :---: |
| **W (Water)** | Nivel de líquido refrigerante dulce (Intercambiador) en su marca. | [ ] |
| **A (Alternator)** | Tensión de la correa del alternador correcta (no hunde más de 1cm). | [ ] |
| **B (Bilge)** | Sentina del motor limpia, sin agua salada ni restos de aceite/gasoil. | [ ] |
| **E (Engine Oil)** | Nivel de aceite del cárter en la marca superior de la varilla. | [ ] |
| **R (Raw Water)** | **GRIFO DE FONDO ABIERTO**. Es vital. Sin él, quemarás el *impeller*. | [ ] |

## 2. Electrónica y Gobierno
| Sistema | Comprobación | Estado |
| :--- | :--- | :---: |
| **Baterías** | Conmutador principal en posición 1, 2 o BOTH. Voltaje > 12.5V. | [ ] |
| **VHF** | Encendida en el Canal 16. Volumen y Squelch ajustados. | [ ] |
| **Plotter/GPS** | Posición GPS adquirida. Carta de la zona cargada. | [ ] |
| **Timón** | Girar rueda a ambas bandas. Comprobar tacto y respuesta. | [ ] |

## 3. Seguridad y Meteorología
| Sistema | Comprobación | Estado |
| :--- | :--- | :---: |
| **Chalecos** | Asignados e inspeccionados. Puestos si el parte es malo. | [ ] |
| **Meteo** | Parte meteorológico revisado para las próximas 12 horas. | [ ] |
| **Escotillas** | Todas cerradas y trincadas (especialmente babor y estribor). | [ ] |

## 4. Maniobra de Salida
1.  **Arranque:** Arrancar motor. **Mirar inmediatamente el escape**: debe salir agua a borbotones (refrigeración salada funcionando).
2.  **Esprines:** Decidir qué esprín usar para pivotar o qué línea soltar primero según el viento.
3.  **Orden final:** *"Soltar amarras, despachar defensas. Listos para zarpar."*
